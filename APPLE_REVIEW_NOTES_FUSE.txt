Apple rejection fixes included in this package:

1) Guideline 2.1(a) - App Completeness
- Fixed customer cart flow.
- Add to cart now works from the home quick items section.

- Logout now works from the profile page and home page when a user session exists.
- Added /restaurants listing page so the Explore/Restaurants navigation no longer opens a missing route.

Suggested review steps:
1. Open the app.
2. Use the home page quick items and tap + to add an item to the cart.
3. Open Cart from the bottom navigation and verify the item appears.
4. Change quantity, then submit the order using the default test phone/address fields.
5. Open Restaurants, choose Fayrouz, and add an item from the restaurant menu.
6. Go to Profile and tap Logout. The app clears the session and returns to Login.
7. For support information, open https://www.fuseiraq.com/support.
