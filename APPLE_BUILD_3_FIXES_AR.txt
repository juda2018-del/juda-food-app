FUSE Iraq - Apple Build 1.0 (3)

الإصلاح الرئيسي:
- إصلاح زر تسجيل الخروج في واجهة الزبون والملف الشخصي ولوحة المطعم والسائق والأدمن.
- إضافة دالة خروج موحدة تمسح جلسة FUSE والكوكيز والتخزين المحلي فوراً.
- إضافة مهلة زمنية لعملية Firebase signOut حتى لا يتجمد الزر داخل iPhone/iPad WebView.
- تحويل المستخدم دائماً إلى شاشة تسجيل الدخول بعد الخروج.
- إصلاح زر تسجيل الخروج في Sidebar لوحة المطعم؛ كان ظاهراً بدون onClick.
- رفع رقم iOS Build من 1 إلى 3 مع بقاء الإصدار 1.0.

التحقق:
- Next.js production compile نجح.
- TypeScript نجح بالكامل.
- توقف الفحص في بيئة الاختبار عند Collecting page data بسبب حد الوقت، وليس بسبب خطأ كود.

قبل الرفع:
1. ارفع هذا المشروع إلى GitHub main.
2. شغّل Build جديد في Codemagic.
3. تأكد أن النسخة في App Store Connect تظهر 1.0 (3).
4. اختبر زر الخروج من حساب customer@fuse.iq قبل الإرسال.
